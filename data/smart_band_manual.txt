智能手环使用指南

产品概述
本智能手环是一款多功能运动健康监测设备，支持全天候心率监测、多种运动模式记录、睡眠质量分析、消息提醒等功能。采用1.1英寸AMOLED高清彩屏，5ATM防水设计，典型续航可达14天。

基本操作

首次配对连接
1. 将手环充电至50%以上电量
2. 在手机应用商店下载配套App并注册账号
3. 打开手机蓝牙功能
4. 进入App，点击首页"添加设备"按钮
5. 选择设备类型"智能手环"
6. App自动搜索附近的手环设备
7. 点击搜索到的设备名称进行配对
8. 手环震动提示配对成功，屏幕显示连接图标

日常佩戴
建议佩戴在手腕骨突起后方约1-2指宽位置，松紧度以可插入一根手指为宜。过松会影响心率监测准确性，过紧则影响舒适度和血液循环。

主要功能

运动模式
手环支持户外跑步、室内跑步、骑行、游泳、健走等多种运动模式。

开启运动记录：
1. 在手环主界面左右滑动找到"运动"图标
2. 点击图标进入运动类型选择界面
3. 上下滑动选择运动类型
4. 再次点击屏幕开始记录
5. 运动过程中可查看实时数据
6. 长按侧边按键停止运动记录

运动数据包括运动时长、消耗卡路里、平均心率、步数等，结束后自动同步至App生成运动报告。

心率监测
手环支持全天候自动心率监测，每隔一定时间自动测量并记录心率数据。

设置监测频率：
1. 打开配套App
2. 进入"设备"-"心率设置"
3. 选择监测频率：智能(自动调节)、1分钟、5分钟、10分钟
4. 设置完成后自动同步至手环

实时测量：在手环主界面找到"心率"图标，点击后静止约10秒可查看当前心率值。

睡眠分析
手环自动识别睡眠状态，记录深睡、浅睡、快速眼动(REM)、清醒时段等数据。

使用方法：
1. 夜间正常佩戴手环入睡
2. 次日早上打开App
3. 数据自动同步显示睡眠报告
4. 可查看睡眠时长、睡眠质量评分、各阶段时长分布

消息通知
手环可接收来电、短信、微信、QQ等应用通知。

开启方法：
1. 打开App进入"设备"-"通知管理"
2. 开启"来电提醒""短信提醒""应用通知"等权限
3. 选择需要推送通知的应用
4. 设置完成后，手机收到消息时手环会震动提示并显示内容

技术规格

防水等级：5ATM(50米防水)
- 支持游泳、淋浴等日常防水场景
- 不支持潜水、跳水、热水浴、桑拿等高温高压场景

续航时间：
- 典型使用：约14天
- 重度使用(高频运动+全天心率监测)：约7天
- 省电模式：可延长至20天以上

充电时间：约2小时充满

屏幕：1.1英寸AMOLED彩色触摸屏，分辨率126×294

传感器：6轴运动传感器、PPG心率传感器、环境光传感器

连接：蓝牙5.0

机身重量：约24克(不含表带)

常见问题

无法连接蓝牙
1. 确认手机蓝牙已开启
2. 确保手环与手机距离小于0.5米
3. 在手机蓝牙设置中取消已配对的手环设备
4. 重启手环：长按侧边按键10秒直至屏幕黑屏后松开
5. 重启手机蓝牙或重启手机
6. 重新在App中搜索配对

无法开机
1. 连接充电器充电30分钟以上
2. 长按侧边按键15秒尝试强制重启
3. 检查充电触点是否有污垢，用干布轻轻擦拭
4. 更换充电器或USB接口重试

数据不同步
1. 确认App在手机后台运行未被清理
2. 在App首页下拉刷新触发手动同步
3. 检查App的蓝牙、定位等权限是否开启
4. 在App中解绑设备后重新绑定

续航时间变短
1. 降低心率监测频率(改为5分钟或10分钟)
2. 减少屏幕亮屏时长和亮度
3. 关闭不常用的消息通知
4. 减少GPS运动模式使用频率

心率数据不准确
1. 确保手环佩戴紧密(但不过紧)
2. 清洁手环背面传感器区域
3. 静止状态下测量更准确
4. 冬季或手部冰凉时数据可能偏差较大

注意事项

1. 首次使用前请充电至50%以上以激活电池
2. 长期不使用时建议每3个月充电一次以保护电池
3. 避免与硬物碰撞或摔落
4. 避免接触化学溶剂、香水、清洁剂等腐蚀性物质
5. 运动后及时清洁汗渍以延长表带寿命
6. 心率等健康数据仅供参考，不能作为医疗诊断依据
7. 固件升级时请保持手环电量充足且不要断开连接
