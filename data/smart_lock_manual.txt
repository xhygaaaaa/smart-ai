智能门锁使用指南

产品概述
本智能门锁是一款集指纹、密码、NFC卡、App、机械钥匙五合一的全自动智能门锁。支持活体指纹识别(0.3秒识别)、虚位密码、远程开锁、临时密码、防撬报警等功能。采用C级锁芯,续航8-12个月,支持App实时查看开锁记录。

基本操作

管理员设置(首次使用必须完成)
1. 按门锁面板上的"*"键激活门锁
2. 按提示录入管理员指纹(建议录入2-3个手指)
   - 将手指平整覆盖识别区
   - 多次按压同一手指(约6-8次,不同角度)
   - 听到"录入成功"提示音
3. 设置管理员密码(6-12位数字)
   - 输入密码后按"#"键确认
   - 重复输入确认密码
4. 系统自动生成机械钥匙编码并提示保存

App绑定
1. 在手机应用商店下载配套App
2. 注册账号并登录
3. 在门锁内侧面板上找到二维码(通常在电池仓盖内侧)
4. 使用App扫描二维码完成绑定
5. 绑定成功后可在App中查看和管理门锁

主要功能

指纹开锁
门锁支持录入最多100枚指纹,识别速度0.3秒,识别率>98%。

使用方法:
1. 将手指平整覆盖指纹识别区(建议大拇指或食指)
2. 听到"嘀"一声后等待识别
3. 识别成功后自动开锁

录入指纹:
1. 按"*"键,按提示输入管理员指纹或密码进入管理菜单
2. 选择"指纹管理"-"添加指纹"
3. 按提示多次按压同一手指(6-8次,不同角度)
4. 录入成功后分配编号(1-100)
5. 可在App中为该指纹命名(如"爸爸""妈妈")

删除指纹:
1. 进入管理菜单-"指纹管理"-"删除指纹"
2. 选择要删除的指纹编号
3. 确认删除

提示:手指干燥、有污渍、冬天手冷时识别率可能下降,建议录入多个手指备用。

密码开锁
门锁支持最多50组密码,每组密码6-12位。

使用方法:
1. 在键盘上输入密码
2. 按"#"键确认
3. 识别成功后自动开锁

虚位密码:
为防止他人偷窥密码,可在正确密码前后添加任意数字,只要连续数字中包含正确密码即可。
示例:正确密码123456,可输入99123456788#,仍可开锁。

添加密码:
1. 进入管理菜单-"密码管理"-"添加密码"
2. 输入新密码(6-12位)并按#确认
3. 重复输入确认
4. 可在App中为该密码命名并设置有效期

删除密码:
在管理菜单中选择"密码管理"-"删除密码",按提示操作。

临时密码
临时密码通过App生成,适合给亲友、保洁、维修人员临时使用。

生成方法:
1. 打开App进入门锁管理页面
2. 选择"临时密码"
3. 选择密码类型:
   - 一次性密码:仅可使用一次
   - 限时密码:设置有效期(如3小时内有效)
   - 周期密码:设置重复时段(如每周一到周五9:00-18:00)
4. 生成后将密码分享给使用者
5. 使用者在门锁键盘输入密码+#即可开锁

临时密码到期后自动失效,无需手动删除。

App远程开锁
需要门锁配备WiFi模块或通过家中网关连接。

使用方法:
1. 打开App,选择门锁设备
2. 点击"远程开锁"按钮
3. 进行身份验证(指纹/面容/密码)
4. 确认开锁,门锁将在30秒倒计时内开启

注意:远程开锁会记录在开锁日志中,App会推送通知。

NFC卡开锁
门锁支持最多50张NFC卡片。

添加卡片:
1. 进入管理菜单-"门卡管理"-"添加门卡"
2. 将NFC卡靠近识别区(通常在把手上方)
3. 听到"录入成功"提示音
4. 可在App中为该卡命名

使用:将NFC卡靠近识别区即可开锁。

手机NFC:部分手机支持NFC功能,可在App中开通虚拟门卡,使用手机NFC贴近门锁开锁。

机械钥匙开锁(应急方式)
当门锁电池耗尽或电子部件故障时使用。

使用方法:
1. 用钥匙或硬币撬开前面板底部的应急钥匙孔盖板
2. 插入机械钥匙
3. 旋转钥匙开锁

注意:机械钥匙请妥善保管,建议一把随身携带,一把存放在安全位置。

安全功能

防撬报警:
门锁内置防撬传感器,面板被撬动时发出高分贝报警音,同时App推送报警通知。

试错锁定:
密码或指纹连续输入错误5次,门锁自动锁定3分钟,期间无法使用密码和指纹开锁(管理员可通过App解除锁定)。

防猫眼开锁:
内侧把手需同时按下防猫眼按钮才能开门,防止通过猫眼用工具开锁。

虚掩报警:
门未关严时,门锁发出提示音提醒。可在App中设置虚掩报警时间(如门未关严超过30秒报警)。

挟持报警:
可设置一组挟持指纹/密码,使用该指纹/密码开锁时门锁正常开启,但会静默发送报警通知到紧急联系人。

开锁记录:
所有开锁记录(指纹/密码/卡片/App/机械钥匙)实时上传App,可查询最近3个月记录。

电池与供电

电池:
门锁使用8节5号碱性电池,安装在内侧电池仓。

续航:
正常使用(每天开锁10次)约8-12个月。

低电量提示:
电量低于20%时,每次开锁后语音提示"电量不足,请及时更换电池"。
电量低于10%时,App推送低电提醒。

更换电池:
1. 打开内侧电池仓盖
2. 取出旧电池
3. 按正负极标识装入新电池(建议使用品牌碱性电池)
4. 盖上电池仓盖

应急供电:
当电池完全耗尽无法开锁时,可使用充电宝(5V)接入门锁底部的Micro-USB应急供电接口临时供电开锁,然后立即更换电池。

技术规格

锁芯等级:C级(防技术开锁时间≥270分钟)
指纹容量:100枚
密码容量:50组
NFC卡容量:50张
指纹识别速度:≤0.3秒
指纹识别率:>98%
工作电压:6V(8节5号电池)
静态功耗:<50μA
动态功耗:<200mA
工作温度:-25℃ ~ 55℃
工作湿度:20% ~ 93%RH
适用门厚:40-110mm

常见问题

指纹识别失败
1. 用干净的布擦净手指和识别区域
2. 确保手指干燥(手湿或手汗过多会影响识别)
3. 尝试换另一只手指
4. 重新录入指纹(多角度按压,增加识别特征)
5. 冬天手冷时先搓热手指再识别

密码无法开锁
1. 检查是否使用了虚位密码(确认正确密码在输入的数字序列中)
2. 检查该密码是否被禁用(在App中查看)
3. 检查是否处于试错锁定状态(等待3分钟或App解锁)
4. 检查电池电量是否充足

门锁无反应
1. 测试按键是否有背光亮起(判断是否通电)
2. 使用充电宝接入应急供电接口测试
3. 检查电池是否正确安装、电量充足
4. 检查电池仓触点是否有锈蚀,用橡皮擦清洁

门锁电池耗尽无法开门
1. 使用充电宝(输出5V)接入门锁底部Micro-USB接口应急供电
2. 供电后使用指纹或密码开锁
3. 开门后立即更换电池
4. 如无充电宝,使用机械钥匙开锁

App显示离线
1. 检查门锁是否通电(电池电量充足)
2. 检查WiFi网关或家庭网络是否正常
3. 重启路由器或网关设备
4. 在App中删除设备后重新绑定

无法添加指纹
1. 确认当前指纹数量是否已满(最多100枚)
2. 按压时确保手指完整覆盖识别区
3. 每次按压后抬起手指再按,不要滑动
4. 尝试多个角度按压
5. 恢复出厂设置后重新录入

注意事项

1. 首次安装后务必测试所有开锁方式,确保正常工作
2. 管理员密码和机械钥匙务必妥善保管
3. 定期(每半年)检查电池电量,及时更换
4. 定期清洁指纹识别区和面板,保持清洁
5. 门锁防水性能有限,安装时注意做好防雨措施
6. 长期外出建议留一把机械钥匙给可信赖的人以备不时之需
7. 不要随意分享管理员权限,普通用户使用普通指纹/密码即可
8. 定期查看开锁记录,发现异常及时处理
9. 固件升级时请保持电量充足,不要中断
10. 如需维修或咨询,请联系官方售后,不要自行拆解

如何重置门锁
1. 恢复出厂设置会清除已录入的管理员、指纹、密码和卡片，需要重新录入
2. 重置前请确认机械钥匙在手边，避免重置后无法进门
3. 重置后按首次使用流程重新完成管理员设置，再录入普通用户指纹和密码
